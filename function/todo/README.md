# Feature - 待办任务 (Todo) UAT

> 销售的行动指令追踪工具。任务由跟进记录归档、节奏提醒、手动创建三种方式产生，具备完成状态追踪与到期提醒，不可删除（只能取消）。

| 属性 | 内容 |
| :--- | :--- |
| **所属 Theme** | T-01 销售过程管理 |
| **需求文档** | `field-specs/05-待办任务.md` |
| **原型** | `prototype/src/pages/03-todos.html` + modals 04 |
| **状态** | UAT 测试中 |
| **Last Updated** | 2026-08-24 |

## 1. 目的

验证待办列表/详情、任务类型、协作跟进及共享对象、关联对象类型（客户/线索/商机级联）、跟进记录生成待办、待办状态及操作（开始/完成/取消）、优先级、到期提醒。

## 2. 范围

| 维度 | 覆盖 |
| :--- | :--- |
| 页面冒烟 | 待办列表标题、7 列表头、我的待办任务卡、逾期/今日到期/即将到期标记 |
| 页面交互 | 筛选、新建任务弹窗、完成按钮、开始按钮 |
| 控件表单 | 任务标题/关联对象类型/优先级/跟进到期时间 |
| 业务流程 | 任务状态流转（待办→进行中→已完成→已取消） |
| 权限/异常 | 任务不可删除（只能取消）、已完成/已取消终态、逾期高亮 |
| 规则回归 | 任务状态枚举、优先级枚举、创建来源枚举、关联对象类型联动 |

### Out of Scope
- 节奏提醒系统触发（需后台任务）
- 到期提醒通知推送
- 跟进记录归档自动生成任务的算法

> **⚠️ 提测待核对**：issue 写「协作跟进及共享对象」，原型下步行动项任务类型含「协作跟进」选项，但「共享对象」配置交互原型未实现。已覆盖任务类型下拉含「协作跟进」；若线上有共享对象配置需补用例。
