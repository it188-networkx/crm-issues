# Feature - 跟进记录 (Followup) UAT

> 销售每次与客户沟通后留下的结构化档案，提交后不可修改删除。验证跟进记录列表/详情/新建、意向等级、触达方式、下步行动、归档、AI 生成跟进要点、搁置/唤醒/失单等跟进动作。

| **需求文档** | `field-specs/01-跟进记录.md` + `field-specs/05-待办任务.md` + `field-specs/06-商机跟进功能审核.md` |
| **AI 文档** | `requirements/ai-augmentation/followup-copilot/` |

## 1. 目的

验证跟进记录全链路：列表筛选与展示、新建跟进（4 种录入方式）、详情页字段（基础信息/录音回放/AI 转写/关键词/商机深度信息）、意向等级、触达方式、立项信号、归档规则（不可修改删除）、AI 生成跟进要点。

## 2. 范围

| 维度 | 覆盖 |
| :--- | :--- |
| 页面冒烟 | 跟进列表标题、10 列表头、详情页基础信息/录音回放/AI 转写/关键词/商机深度信息区块 |
| 页面交互 | 筛选、新建跟进入口、4 种录入方式切换、详情页 AI 转写折叠展开 |
| 控件表单 | 触达方式、意向等级、立项状态、立项触发方式、跟进关键词标签 |
| 业务流程 | 跟进记录归档、归档后不可修改删除、归档生成待办 |
| 权限/异常 | 跟进记录只读约束、归档状态徽章 |
| 规则回归 | 意向等级枚举、触达方式枚举、创建类型、转写状态、立项状态同步 |

### Out of Scope
- 语音转写服务（需真实 AI 服务）
- 渠道同步/自动触达写入（Phase 3）
- AI 提取算法的准确性（仅验证展示与交互）

| 新建跟进页 | 4 种录入方式：语音录入/录音导入/粘贴文本/完整表单 |
