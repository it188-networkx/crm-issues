# Feature - 客户/联系人 (Account & Contact) UAT

> 客户是 CRM 核心主数据，下挂联系人、跟进记录、商机。验证客户列表/详情、新增/编辑、客户类型、行业、状态、活跃状态、联系人功能、客户与商机/跟进关联。

| 属性 | 内容 |
| :--- | :--- |
| **所属 Theme** | T-01 销售过程管理 |
| **需求文档** | `field-specs/03-客户基础信息.md` + `field-specs/02-联系人.md` |
| **原型** | `prototype/src/pages/09-accounts.html` + `10-account-detail.html` + `11-contact-create.html` + `12-contact-detail.html` |
| **状态** | UAT 测试中 |
| **Last Updated** | 2026-08-24 |

## 1. 目的

验证客户列表/详情/新增、客户类型（终端/渠道）、行业、客户状态、活跃状态、联系人新建（决策链角色/决策权重/项目态度）、客户与商机/跟进关联、AI 聚合跟进历史摘要。

## 2. 范围

| 维度 | 覆盖 |
| :--- | :--- |
| 页面冒烟 | 客户列表标题、9 列表头、详情页 Tabs（基础信息/联系人/跟进时间线）、核心信息/归属与商务/修改日志/关联商机区块 |
| 页面交互 | 客户筛选、新增弹窗、详情 Tabs 切换、补充洞察折叠 |
| 控件表单 | 公司简称/行业/客户类型/状态/获客来源/负责人筛选、联系人新建表单 |
| 业务流程 | 客户新增、联系人新增、决策链角色/权重设置 |
| 权限/异常 | 客户状态徽章、企查查风险认证、BPMS 回款信用 |
| 规则回归 | 客户状态枚举、行业枚举、企业性质枚举、决策链角色枚举、联系人状态联动客情降级 |

### Out of Scope
- 集团树多层级分析
- AI 联网搜索自动补全（需 AI 服务）
- EDM 邮箱有效性回写
- 联系人跨客户迁移审批

## 3. 测试域

| 域 | 说明 |
| :--- | :--- |
| 客户列表页 | 菜单：客户管理；筛选（公司简称/行业/客户类型/状态/获客来源/负责人）；9 列表头 |
| 客户详情页 | Tabs：基础信息/联系人/跟进时间线；核心信息/归属与商务/补充洞察/修改日志/关联商机 |
| 联系人新建 | 基本信息（姓名/职位/部门/手机/邮箱/微信）+ 决策链信息（角色/权重/偏好沟通/状态/客情状态/项目参与） |
