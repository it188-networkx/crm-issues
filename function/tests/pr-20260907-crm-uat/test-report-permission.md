## 二、发现的问题（Bug）

### BUG-GP-01【高】决策看板菜单对所有角色可见（权限未启用却可见）

- **问题模块**：全局权限
- **问题功能**：决策看板菜单权限
- **实际表现**：
  - 系统管理员（admin）角色可见「💹 决策看板」菜单
  - **销售（sales）角色也可见「💹 决策看板」菜单，且可点击进入 `/crm/decision-board` 页面**
- **预期表现**：权限矩阵 `CRM角色权限矩阵.md` 第 86/88 行明确「📊 决策看板 ⚠️ 未启用：菜单已在系统内定义（`crm:decision-board`），当前所有角色均未分配该菜单权限，功能未上线」——所有角色（含销售）都不应看到决策看板菜单
- **复现步骤**：
  1. 登录系统，切换角色为「销售」
  2. 观察左侧菜单，仍有「💹 决策看板」
  3. 点击「决策看板」，可正常进入页面
- **原型对应位置**：左侧导航菜单
- **关联需求文档**：`field-specs/CRM角色权限矩阵.md` §菜单权限矩阵（第 86/88 行）
- **严重程度**：高（未启用功能的菜单对无权限角色可见且可进入）
- **截图**：`screenshots/gp-01-sales-role.png`、`screenshots/gp-02-sales-decision-board.png`

### BUG-GP-02【中】CEO/主管撤销「标记人=主管」的星标时按钮文案错误（显示「取消星标」而非「申请移出」）

- **问题模块**：全局权限
- **问题功能**：星标撤销按钮文案（非对称权限前端展示）
- **实际表现**：
  - CEO（landcai）对「标记人=销售主管（蔡正礼）」的星标，列表页和详情页操作按钮均显示「**取消星标**」
  - 点击「取消星标」后被后端拦截（422）：「该星标由他人标记，不能直接撤销，请走申请移出」
- **预期表现**：按 2026-08-26 定案规则 5「销售主管/售前主管/CEO 两两互不直接撤，互撤走『申请移出』审批」。前端按钮应显示「申请移出」（如销售 cuizhibo 视角对主管星标正确显示「申请移出」）
- **复现步骤**：
  1. 销售主管 caizhengli 给商机「请问-测试-冠服联平台-测试」（负责销售=崔志波）加星
  2. 登录 CEO landcai，进入该商机列表/详情
  3. 观察操作按钮显示「取消星标」（应显示「申请移出」）
  4. 点击「取消星标」→ 后端 422 拦截「该星标由他人标记，不能直接撤销，请走申请移出」
- **原型对应位置**：商机列表操作列、商机详情星标按钮
- **关联需求文档**：`CRM角色权限矩阵.md` §权限点 `crm:opp:star`（规则 5）
- **严重程度**：中（后端校验正确，前端按钮文案/入口逻辑缺陷，误导用户点击后才报错）
- **截图**：`screenshots/star-ceo-vs-leader-wrong-button.png`、`screenshots/star-apply-remove-dialog.png`

### 星标非对称权限（真实多账号验证完成）

| 定案规则 | 结果 | 验证方式 |
| :--- | :--- | :--- |
| 规则1 标记人可撤销自己的星 | ✅ | 销售主管 caizhengli 撤销自己加的星 → Toast「已取消星标」直接生效 |
| 规则2 销售仅可标记本人负责商机 | ✅ | 销售 cuizhibo 给自己负责商机加星成功；列表仅展示本人商机（35条） |
| 规则3 销售撤他人星→申请移出 | ✅ | 主管 caizhengli 给崔志波商机加星后，崔志波视角操作列显示「**申请移出**」（非「取消星标」）；点击弹「申请移出预测监测」：⚠️该星标由他人标记，需标记人审批后方可移出；审批通过前星标保持有效 |
