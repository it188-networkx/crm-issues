## 一、测试结论总览

本次对 CRM 6 大模块（商机/跟进记录/客户联系人/待办任务/决策看板周报/全局字段权限）进行了**完整功能验收测试**（第一轮逐页核对 + 第二轮闭环流程补测 + 真实多账号权限补测），共发现 **14 个确认 bug + 4 个待确认项**。

| 模块 | 问题数 | 主要发现 |
| :--- | :---: | :--- |
| 1. 商机 | 6 | 状态多「回退」、阶段「签约交付中」、过单 S3 文案、业务场景未自动推导、保留「标记成交」、停滞超期标签缺失 |
| 2. 跟进记录 | 3 | 意向等级旧 4 档、触达方式值不符、缺聚合视图切换 |
| 3. 客户/联系人 | 1 | 客户类型缺「企业客户」 |
| 4. 待办任务 | 1 | 缺「取消」操作与「已取消」状态 |
| 5. 决策看板/周报 | 1 | 仅剩周报 Tab，缺周会战报 Tab |
| 6. 全局字段/权限 | 2 | 决策看板菜单对销售可见；CEO/主管平级撤星按钮文案错误 |

**待确认项（4 个）**：① 跨阶段跳转门控缺失（配置 vs bug）；② 联系人部门必填性口径冲突；③ 新增客户弹窗字段与规则9不符；④ 行业字典 11 vs 18 项。

## 二、问题清单（汇总 · 按 issues 记录模板）

### 高优先级（11 个）

#### BUG-OPP-01【高】商机状态枚举多出「回退」状态
- **问题模块**：商机
- **问题功能**：商机状态（`opp_status`）枚举
- **实际表现**：筛选器「商机状态」下拉 5 项：活跃/回退/成交/失单/搁置；详情页出现值为「回退」的数据
- **预期表现**：4 态：活跃/搁置/成交/失单。「回退」是阶段操作动作（`stage_action='rollback'`），不改变商机状态
- **复现步骤**：商机管理 → 筛选器「商机状态」→ 见「回退」项
- **需求依据**：`10-商机阶段状态操作卡.md` §3/§4
- **截图**：`screenshots/opp-01-status-filter.png`

#### BUG-OPP-02【高】阶段「签约交付中」≠「签约中」（列表/看板未改，仅详情已改）
- **问题模块**：商机
- **问题功能**：当前阶段枚举
- **实际表现**：列表筛选器/看板第 9 阶段显示「签约交付中」，详情流转显示「签约中」，三处不一致
- **预期表现**：9 推进阶段第 9 位应为「签约中」
- **复现步骤**：商机管理筛选器「当前阶段」+ 看板 + 详情流转三处对比
- **需求依据**：`04-商机.md` 规则 27；checklist C4（已知缺陷，列表/看板未修复）
- **截图**：`screenshots/opp-04-stage-filter.png` 等

#### BUG-OPP-04【高】新建商机「业务场景需求」未按 R 线自动推导
- **问题模块**：商机
- **问题功能**：新建商机弹窗自动推导
- **实际表现**：勾选 R9 后「业务场景需求」仍为空的手动下拉（readonly=false）；连锁影响商机名称拼接缺「业务场景」段（名称=「请问-测试名称拼接」而非「请问-冠服联平台-测试名称拼接」）
- **预期表现**：仅 R9→冠服联平台；仅 R1a→冠网CPE·网关；并存→组合场景；仅非自研→传统ICT
- **复现步骤**：商机管理 → 新增 → 选客户「请问」→ 勾 R9 → 业务场景仍空
- **需求依据**：`04-商机.md` §核心信息（08-26 定案）
- **截图**：`screenshots/opp-10-scene-not-derived-confirmed.png`

#### BUG-OPP-05【高】保留「✅ 标记成交」按钮+手动成交表单
- **问题模块**：商机
- **问题功能**：跟进创建页「阶段/状态操作」卡片
- **实际表现**：阶段操作卡片含「✅ 标记成交」按钮，点击展开成交金额/签约日期/归因渠道/关键影响因素表单
- **预期表现**：成交只能由 BPM 合同签署回调回写，CRM 不提供手动成交（原 sa-win 已废除）
- **复现步骤**：新建跟进（完整表单）→ 关联商机 → 点「✅ 标记成交」→ 展开表单
- **需求依据**：`10-商机阶段状态操作卡.md` §一/§五（08-27 定案）
- **截图**：`screenshots/opp-stage-action-card-has-win-button.png`

#### BUG-OPP-07【高】停滞超期标签缺失
- **问题模块**：商机
- **问题功能**：风险标签「停滞超期」+ 详情琥珀提示条
