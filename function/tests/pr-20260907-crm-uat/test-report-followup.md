## 二、发现的问题（Bug）

### BUG-FU-01【高】意向等级枚举仍为旧 4 档，未更新为 3 值字典

- **问题模块**：跟进记录
- **问题功能**：意向等级（`crm_followup_intent`）枚举
- **实际表现**：跟进列表筛选器「意向等级」下拉选项为 4 值：`强意向 / 有兴趣 / 一般 / 冷淡`；跟进详情页「意向等级」字段值显示「强意向」
- **预期表现**：意向等级应为 3 值：`近期成交 / 持续跟进 / 长期培育`。需求 `01-跟进记录.md` 第 110 行明确「原 4 档『冷淡/一般/有兴趣/强意向』已弃用」，2026-08-25 对齐线上 `crm_followup_intent` 字典 3 值
- **复现步骤**：
  1. 进入「跟进记录」，点击筛选器「意向等级」
  2. 观察下拉选项为「强意向/有兴趣/一般/冷淡」4 值
- **原型对应位置**：跟进列表筛选器「意向等级」、跟进详情「意向等级」
- **关联需求文档**：`field-specs/01-跟进记录.md` §基础信息（意向等级 3 值）+ §意向等级（原 4 档已弃用）
- **严重程度**：高（枚举未更新，影响筛选与统计口径）
- **截图**：`screenshots/fu-02-intent-filter.png`
- **备注**：`review/online-vs-prototype-extract-checklist-20260827.md` 条目 3-1 记载「线上为准，线上 3 值」，但**实测线上为 4 值旧口径**，与 review 清单记载不符（清单可能基于旧快照）

### BUG-FU-02【高】触达方式枚举与需求 5 项不一致

- **问题模块**：跟进记录
- **问题功能**：触达方式枚举
- **实际表现**：线上筛选器「方式」下拉选项为：`微信 / 电话 / 邮件 / 现场拜访 / 线上会议`
- **预期表现**：需求应为 `电话 / 会议 / 到访 / 邮件 / 企业微信`（5 项，2026-08-25 对齐线上字典）
- **复现步骤**：
  1. 进入「跟进记录」，点击筛选器「方式」
  2. 观察下拉选项为「微信/电话/邮件/现场拜访/线上会议」
- **原型对应位置**：跟进列表筛选器「方式」、跟进详情「触达方式」
- **关联需求文档**：`field-specs/01-跟进记录.md` §基础信息（触达方式 5 项）
- **严重程度**：高（枚举值不一致：「现场拜访」≠「到访」、「线上会议」≠「会议」、「微信」≠「企业微信」）
- **截图**：`screenshots/fu-03-way-filter.png`

### ~~BUG-FU-03~~ 已撤销（推动方式枚举正确，为误判）

- **原判断（错误）**：曾误判「推动方式枚举仍为旧 3 值（客户自主推进/我方参与推动/不明确）」
- **复核结论（正确）**：推动方式在新建跟进「完整表单」模式中实测为 `客户推动 / 我方参与推动`（**2 值，符合 2026-08-25 定案**）
- **误判原因**：首次抓取下拉选项时把多个 Arco 下拉的 option 混在一起统计，把「不明确」等来自其他下拉的值误归入推动方式。重新单独验证后确认推动方式枚举正确，撤销本条

### BUG-FU-04【中】跟进列表缺「聚合视图/明细视图」切换

- **问题模块**：跟进记录
- **问题功能**：列表聚合视图（`_fuToggleAgg`）
- **实际表现**：跟进列表 `/crm/followup` 页仅有明细表格，**无「👥 聚合视图 / 📋 明细视图」切换按钮**；无法按「客户 × 阶段」聚合展示跟进要点
- **预期表现**：按 `01-跟进记录.md` §列表聚合视图（2026-08-31 补录 · CR-WR-05A）：列表页提供「👥 聚合视图 / 📋 明细视图」切换（默认明细），聚合键=客户×阶段，聚合视图列=客户（带×N 次数角标）/阶段/跟进要点汇总/最近跟进
- **复现步骤**：
  1. 进入「跟进记录」
  2. 观察列表页无聚合视图切换按钮
- **原型对应位置**：跟进列表页（`pages/04-followups.html` + `js/10-drilldown.js`）
- **关联需求文档**：`field-specs/01-跟进记录.md` §列表聚合视图（2026-08-31 补录 CR-WR-05A）
- **严重程度**：中（08-31 新增需求未实现）
