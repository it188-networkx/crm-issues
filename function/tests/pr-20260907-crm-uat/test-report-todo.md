## 二、发现的问题（Bug）

### BUG-TD-01【高】待办任务缺「取消」操作与「已取消」状态

- **问题模块**：待办任务
- **问题功能**：任务操作与状态枚举
- **实际表现**：
  - 待办列表操作列只有「✓ 完成」「查看」两个操作，**无「取消」按钮**
  - 待办列表状态筛选器只有「待办 / 已完成」2 值，**无「已取消」选项**
  - 新建任务弹窗「状态」字段固定为「待办」（禁用），无取消相关入口
- **预期表现**：需求 `05-待办任务.md` 规则 1「任务不可删除，只能通过『取消』操作写入取消时间转为已取消」；规则 2「完成/取消时间只能通过『完成』『取消』两个操作按钮触发」；生命周期「待完成 → 已完成 / 已取消」，已取消为终态
- **复现步骤**：
  1. 进入「待办任务」
  2. 观察任意待办任务行的操作按钮，只有「✓ 完成」「查看」，无「取消」
  3. 点击状态筛选器，选项只有「待办/已完成」，无「已取消」
- **原型对应位置**：待办列表操作列、状态筛选器、新建任务弹窗
- **关联需求文档**：`field-specs/05-待办任务.md` §关键业务规则 1/2、§任务生命周期总览
- **严重程度**：高（核心操作「取消」缺失，任务无法取消）
- **截图**：`screenshots/td-01-list.png`、`screenshots/td-02-create-modal.png`
