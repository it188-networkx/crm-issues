# Feature - 销售周报生成 (Weekly Report Generation)

> AI 驱动销售个人周报自动生成：系统每周自动聚合数据，AI 生成结构化周报，销售确认后管理层集中查阅。

| 属性 | 内容 |
| :--- | :--- |
| **所属 Theme** | T-03 决策驾驶舱 |
| **Epic** | E-06 销售周报生成 |
| **需求文档** | `weekly-report-prd.md` + `weekly-report-plan.md` |
| **原型** | `full-prototype-standalone.html` |
| **状态** | 规划中 · Phase 2 |
| **Last Updated** | 2026-08-11 |

## 1. 目的

验证销售周报模块的全链路功能：周报列表渲染、详情展示、分析区块、状态流转、权限隔离、评论/审核/标记已阅交互。

## 2. 范围

| 维度 | 覆盖 |
| :--- | :--- |
| 页面冒烟 | 决策看板周报 Tab、完整列表页入口、8 张指标卡、分析区块、管道快照 |
| 页面交互 | 筛选、内联展开详情、折叠明细、团队交叉对比面板 |
| 控件表单 | 周期/状态/销售多选筛选、评论关联引用三字段级联 |
| 业务流程 | 确认 → 修订后确认 → 标记已阅 → 评论 |
| 权限/异常 | 销售仅见本人、标记已阅权限约束(仅主管/CEO/pending)、空态占位 |
| 规则回归 | 状态机 pending→confirmed→confirmed-edited→auto |

### Out of Scope
- 定时任务触发（周六 18:00 生成、周日 22:00 自动确认）— 需造数据或后台触发
- 通知推送内容
- 导出 PDF/Markdown 功能
- Phase 3 会议纪要/待办核验

## 3. 测试域

| 域 | 说明 |
| :--- | :--- |
| 周报预览表（决策看板 Tab） | 管理层默认当前周团队快照，销售默认本人全部周期 |
| 周报完整列表页 | `/crm/weekly-report`，含全部筛选与团队交叉对比 |
| 展开详情 | 8 张指标卡 + 明细区块 + 分析区块 + 风险分层 + AI 原始生成折叠 |
| 确认 / 审核修改 | 确认弹窗、审核弹窗、修订日志 |
| 标记已阅 / 评论 | 权限约束 + 一人一次 + 关联引用 |

## 4. 页面对象 & 选择器

| PO 方法 | 定位策略 | 说明 |
| :--- | :--- | :--- |
| `goto_weekly_report_tab` | 决策看板 → 销售周报 Tab | 预览表入口 |
| `goto_weekly_report_list` | `/crm/weekly-report` | 完整列表页 |
| `verify_8_indicator_cards` | `.wr-card` × 8 | 跟进覆盖/跟进/推进/新增/回退/成交/失单/逾期 |
| `verify_analysis_blocks` | 成功点/失败点/亮点/风险提示卡片 | 4 区块渲染 |
| `verify_risk_source_badge` | `source=rule` / `source=ai` | 风险分层徽章 |
| `verify_status_badge` | 待确认/已确认/修订后确认/系统代确认 | 状态徽章颜色 |
| `click_expand_detail` | `展开 ▼` 按钮 | 内联展开详情 |
| `verify_mark_read_visible` | `标记已阅` 按钮 | 仅 pending + 主管/CEO 可见 |
