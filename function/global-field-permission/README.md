# Feature - 全局字段/权限 (Global Field & Permission) UAT

> 验证全局字段名称/类型/枚举/必填规则、菜单及功能入口、不同角色的页面及功能权限、数据权限、AI 辅助能力、全局组件交互。

| 属性 | 内容 |
| :--- | :--- |
| **所属 Theme** | 全局 |
| **需求文档** | `field-specs/crm-field-mapping-full.md` + `architecture/full-system-menu-design.md` + `field-specs/CRM角色权限矩阵.md` |
| **原型** | 全局（角色切换器/菜单/字段） |
| **状态** | UAT 测试中 |
| **Last Updated** | 2026-08-24 |

## 1. 目的

验证 7 种角色的菜单权限矩阵、数据范围（角色即数据边界）、关键字段的枚举与必填规则、全局组件（通知中心/角色切换器）交互。

## 2. 范围

| 维度 | 覆盖 |
| :--- | :--- |
| 页面冒烟 | 全局菜单结构、通知中心、个人中心 |
| 页面交互 | 角色切换、菜单导航、通知铃铛 |
| 控件表单 | 全局必填字段标记（`*`）、枚举下拉 |
| 业务流程 | 角色数据范围隔离（销售仅本人） |
| 权限/异常 | 菜单权限矩阵（7 角色 × 16 菜单）、决策看板权限 |
| 规则回归 | 角色定义（R-01~R-07）、数据范围、菜单可见性 |

### Out of Scope
- 数据权限的后端强制（仅验证 UI 可见性）
- AI 辅助能力的生成逻辑（仅验证入口）

## 3. 测试域

| 域 | 说明 |
| :--- | :--- |
| 菜单权限 | 16 个菜单 × 7 角色：首页/工作台/跟进记录/线索/客户/商机/EDM/营销自动化/知识库/决策看板/数据接入/标签/业务配置/AI配置/用户权限 |
| 角色定义 | R-01 admin / R-02 mkt-leader / R-03 sales / R-04 presales / R-05 executive / R-06 sales-leader / R-07 presales-leader |
| 数据范围 | 销售=仅本人；销售主管=本人+团队；售前=仅参与商机；售前主管=商机全部只读；CEO=全部只读；admin=全部 |
